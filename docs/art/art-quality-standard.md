# 美术资源质量标准

资源只有同时通过“自动技术检查、人工视觉检查、游戏内检查”才能进入 `VERIFIED`。自动化只保证文件能被使用，不判断是否好看或符合语义。

## 通用硬性规则

| 项目 | 自动检查 | 人工检查 |
|---|---|---|
| 文件与命名 | PNG/JPG 路径存在、命名符合资源管理规范、清单有对应记录。 | ID、用途和游戏配置语义一致。 |
| 尺寸与比例 | 像素尺寸、精灵表帧数、文件大小合理。 | 游戏目标显示尺寸下轮廓清晰、不变形。 |
| Alpha | 需要透明的资源四角 alpha 为 0、主体有可见像素。 | 无白边、绿/紫色溢、假透明底或被裁断的主体。 |
| 文本与重复 | 可通过肉眼和接触表发现异常。 | 无文字、水印、伪字符、重复角色或与已有资源过度相似。 |
| 可追溯性 | `asset-manifest.md` 有来源、版本、状态和 QC 链接。 | 生成条件足以大致复现，失败原因可理解。 |

## 分类验收

| 类型 | 自动技术项 | 人工与实机项 |
|---|---|---|
| 宠物 / Boss / NPC | 正式尺寸分别为 `1024²` / `1024²` / `512²`；透明角与主体像素；宠物图标派生尺寸为 256/128/64。 | 全身完整、留白充足、轮廓和属性特征清楚；与同属性角色剪影有区分；图鉴、仓库、Boss 页、对话框实际显示无裁切。 |
| 地图 props / 精灵 | `32×32`、透明背景、加载键存在。 | 地图同尺度、可辨认、不遮挡格子或交互标记；Phaser 实机加载正常。 |
| Tileset | `128×32`，四个 `32×32` 格；Tiled 加载成功。 | 俯视光源、道路/水面/边界自然；预览和实际地图均无接缝、错位或错误 gid。 |
| VFX | `1024×256` 透明 PNG；4 帧 `256²` 均有可见像素。 | 中心锚点稳定，四帧节奏完整；不遮挡 HP/行动信息；元素颜色和技能语义可辨；战斗事件触发正确模板。 |
| UI / 状态 / 技能图标 | 属性/状态 `128²`、技能类型 `256²`，透明角；调用映射存在。 | 24px 仍能区分语义；粗轮廓统一；不依赖图中文字；导航、新游戏、技能和战斗页无错图。 |
| 道具 | `256²` 透明 PNG，`item_<ITEM_ID>.png` 可由共享 helper 找到。 | 小尺寸可辨、类别/元素表达清楚；背包和商店无错图或背景色溢。 |
| 背景 / 场景 / 事件插画 | 背景 `1920×1080`、缩略图 `256²`、事件 `512²`；不要求 alpha。 | 主体不被覆盖缩放裁掉；战斗、主页、地图缩略图、随机事件页构图正确，无文字水印。 |

## 检查顺序与结论

1. 先执行已有脚本自带的尺寸、边界或帧检查；运行 `frontend/scripts/verify-skill-art-adaptation.ps1` 复核技能池映射变更。
2. 对成组资源生成 contact sheet；人工逐项检查风格、轮廓、重复、文字和裁切。
3. 运行 `vue-tsc -b` 与 `npm run build`；涉及游戏配置时再运行对应后端测试。构建通过不等于运行时通过。
4. 在实际使用场景截图检查。地图要进入地图，VFX 要触发战斗事件，图标要看目标缩放尺寸。
5. 记录 `通过 / 退回生成 / 退回后处理 / 退回接入`。只有“通过”才更新为 `VERIFIED`。

## 常见失败与处理

| 现象 | 根因倾向 | 处理 |
|---|---|---|
| 背景没有透明或出现色边 | 生成器未输出可用 alpha、绿幕不纯或抠图不足。 | 回到候选；纯绿幕可重跑抠图，非纯背景或强色溢则重生。 |
| 主体贴边、被裁切 | Prompt 留白要求缺失，或误用覆盖缩放脚本。 | 重生并要求 10% 留白；透明主体不使用 `prepare-raster-asset.ps1`。 |
| 角色同质化 / 风格漂移 | 批次过大或可变描述侵蚀固定风格块。 | 以已通过锚点对照，小批量重生；锁定视角、光源、描边和主色数。 |
| VFX 不像技能或遮挡 UI | 按技能名而非视觉语义选模板，中心/范围失控。 | 调整共享模板映射或重生模板，不为单个同义技能复制新特效。 |
| Tileset 有接缝 | 只做了尺寸检查，未测试拼接。 | 重做源图或切片，必须在预览和真实地图双检。 |
| 资源存在但页面没用到 | 未更新共享 helper、加载场景或视图映射。 | 以资源管理中的“实际接入点”逐项定位，补最小映射并实机验证。 |

# 美术生成提示词模板

以下模板来自已通过的 Batch 0～8 约束。方括号是每次填写的可变字段；其余固定块不要随意删除。实际使用的模型名称/版本、输出比例和后处理方式须记入 `asset-manifest.md`，不在此虚构固定参数。

## 全局固定块

```text
清新幻想的 2D 游戏插画，圆润造型，轻微手绘颗粒，深蓝灰中等描边，
左上方暖白主光、右下方柔和冷色环境光，柔和饱和配色，干净清晰的游戏可读性。
禁止：写实风、暗黑风、像素风、文字、logo、水印、UI 框、伪字符、复杂背景、主体裁切。
```

属性色仅作为主色、局部发光或材质提示：金 `#C9B037`、木 `#66BB6A`、水 `#42A5F5`、火 `#EF5350`、土 `#8D6E63`、风 `#80CBC4`、雷 `#FFCA28`、光 `#FFF176`、暗 `#7E57C2`。

## 宠物 / Boss / NPC

```text
【用途】游戏 [宠物/Boss/NPC] 立绘，ID 为 [ID]，将在 [页面/组件] 以 [显示尺寸] 展示。
【主体】[名称]，[属性]，[定位]；外形为 [剪影、物种、材质]；关键识别点为 [2～3 个特征]。
【差异】与 [相近角色] 的区别是 [剪影/部件/元素形态]，不可复用其姿态或主轮廓。
【构图】全身，3/4 视角，面向左前方，居中，四周至少 10% 留白，主体完整。
【风格】[粘贴全局固定块]；使用 [2～4] 个主色，主属性色为 [色值]。
【背景】纯净 #00FF00 绿幕，主体不含投影到画布边缘；后续会转换为透明 PNG。
【规格】正方形 [1024/512] × [1024/512]；不要文字、边框、水印或场景背景。
```

宠物新系列先生成不超过 3 个风格锚点；同批次最多 3 只。Boss 使用 `1024²`，NPC 使用 `512²`，其余规则与宠物一致。

## 地图 props / 场景物件

```text
【用途】俯视地图中的 [player/camp/chest/gather/...]，32px tile 对齐。
【主体】[物件描述]，交互语义为 [用途]，轮廓必须在小尺寸下可辨。
【构图】正交俯视、单个完整物件、居中、四周留少量透明边距。
【风格】[粘贴全局固定块]，与地图同为左上方光源；简洁，避免微小装饰。
【背景】纯净 #00FF00 绿幕，后续抠为透明 PNG。
【规格】先生成清晰方图，导出为 32×32；禁止人物肖像、文字、地平线或独立场景背景。
```

## Tileset

```text
【用途】区域 [area-id] 的俯视正交 2D tileset；需要 [草地/水面/道路/遗迹] 四种可拼接地表块。
【画面】2×2 方格源图，每格边界明确、纹理可无缝延续、左上方光源一致。
【风格】清新幻想、柔和手绘质感、低对比细节；与现有 tileset 尺度一致。
【规格】无文字、无角色、无透视、无投影超出格子；后续切为 4 个 32×32 格、合成 128×32 PNG。
```

Tileset 是唯一必须先做“拼接测试”的类型；不要把完整景观插画当作 tileset。

## 战斗特效（透明 PNG sprite sheet）

```text
【用途】技能/事件 [skill-or-event] 的 [属性/功能] 战斗特效，复用模板 [template]。
【主体】[元素形态与运动方向]，峰值语义为 [爆裂/护盾/治疗/束缚/...]，轮廓简洁。
【风格】[粘贴全局固定块]；使用 [属性色]，半透明圆润粒子，不含 UI。
【构图】中心锚定，特效不触碰画布边缘，四周保留安全透明区。
【背景】原生透明背景；如不可用则纯净 #00FF00 绿幕后抠图。
【规格】单个清晰主体；后续统一生成横向 4 帧 256×256 精灵表（起势、峰值、余波、消散），12 FPS、非循环。
【禁止】文字、命中数字、角色、场景、屏幕级闪白、边框。
```

先检查是否能映射到既有 31 个模板；只有确实新增视觉语义时才生成新模板。

## UI / 图标 / 道具

```text
【用途】[属性/状态/技能类型/道具] 图标，ID 为 [ID]，目标显示尺寸约 [24/32]px。
【语义】一眼可读的 [盾牌/水滴/火焰/书本/...] 剪影；主色为 [颜色]，辅助色不超过 2 种。
【风格】[粘贴全局固定块]，粗描边，高对比，几何轮廓干净，细节克制。
【构图】居中、四周透明留白、不要文字；缩小后仍能辨认。
【背景】原生透明背景；如不可用则纯净 #00FF00 绿幕后抠图。
【规格】[128/256] × [128/256] PNG；禁止 UI 面板、按钮外框、说明文字、水印。
```

统一系列图标可先生成整表再用 `split-ui-icon-sheet.ps1` 切片；道具仅在不能由现有底图、元素徽记和脚本派生时单独生成。

## 背景 / 区域缩略图 / 事件插画

```text
【用途】[战斗背景/主页背景/区域缩略图/事件插画]，区域或事件为 [ID/名称]。
【画面】[前景、中景、远景或事件主体]，保留 [UI 覆盖区域] 的干净留白；叙事重点为 [主题]。
【风格】[粘贴全局固定块]，场景允许完整不透明背景，光源仍为左上方。
【规格】[1920×1080 / 512×512 / 256×256]，无文字、logo、水印、角色头像框或 UI。
```

背景不得要求透明，也不要用透明主体的裁切脚本处理；区域缩略图从已审核背景派生时，先检查裁切后仍保留区域辨识点。

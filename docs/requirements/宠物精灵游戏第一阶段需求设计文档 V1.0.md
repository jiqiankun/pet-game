**产品定位：个人开发、个人部署、个人游玩的轻量宠物收集养成游戏**

---

## 1. 项目定位

### 1.1 游戏定位

本项目是一款以：

**宠物收集 + 自由培养 + 队伍构筑 + 回合制战斗 + 区域探索 + Boss挑战**

为核心玩法的轻量单机宠物精灵游戏。

游戏优先面向个人长期游玩，不考虑商业运营、多人竞争和复杂在线系统。

核心设计原则：

> **系统可以有深度，但操作和实现不能过重。**

第一阶段重点验证：

1. 捕捉宠物是否有持续乐趣；
2. 不同宠物是否具有明显差异；
3. 自由加点和技能组合是否能够形成Build；
4. 3宠同时上场的队伍战斗是否具有策略性；
5. Boss重复挑战是否具有持续目标；
6. 图鉴、资质、稀有技能是否能够驱动长期收集。

# 2. 第一阶段核心循环

核心循环：

```text
进入区域
  ↓
探索地图
  ↓
发现野生宠物 / 事件 / 资源
  ↓
进入战斗
  ↓
击败 / 捕捉
  ↓
获得金币、经验池、材料、宠物
  ↓
培养宠物
  ├─ 升级
  ├─ 分配自由属性点
  ├─ 解锁技能
  └─ 调整技能组合
  ↓
调整6宠队伍
  ↓
挑战区域Boss
  ↓
解锁新区域 / 高难Boss
  ↓
继续收集与培养
```

长期循环：

```text
重复捕捉
↓
寻找高资质 / 稀有技能 / 特殊外观
↓
保留优秀个体
↓
放生多余宠物获得临别礼物
↓
培养不同Build
↓
挑战困难 / 噩梦Boss
↓
完善图鉴与研究
```

# 6. 属性克制

基础关系：

```text
金 → 木
木 → 土
土 → 水
水 → 火
火 → 金

金 → 风
风 → 雷
雷 → 水

光 ⇄ 暗
```

### 默认倍率

| 情况 | 倍率 |
|---|---:|
| 克制 | ×1.50 |
| 普通 | ×1.00 |
| 被克制 | ×0.75 |

第一阶段不存在完全属性免疫。

所有倍率配置化。

---

# 7. 本属性技能加成

宠物使用与自身属性相同的技能：

> **效果 ×1.20**

例如：

火属性宠物释放火属性攻击：

```text
基础伤害
× 属性克制
× 1.20本属性加成
```

跨属性技能不获得本属性加成。

---

# 8. 宠物战斗属性

第一阶段采用六维属性。

| 属性 | 作用 |
|---|---|
| 生命 | 最大HP |
| 力量 | 主要影响物理型技能 |
| 灵力 | 主要影响元素/特殊技能 |
| 防御 | 降低物理伤害 |
| 抗性 | 降低灵力/元素伤害 |
| 速度 | 决定行动顺序 |

---

# 9. 宠物属性组成

最终属性来源：

```text
种族基础属性
+
个体基础浮动
+
等级固定成长
+
资质成长修正
+
自由属性点
+
战斗Buff/Debuff
```

同种宠物保持相同的大方向定位，但允许存在个体差异。

---

# 10. 个体基础差异

同一种宠物捕获时，其初始六维允许围绕种族标准值：

> **约±5%浮动**

目的：

- 同种宠物不完全一致；
- 但不能出现过大的出生差距；
- 真正长期差异主要由资质和玩家培养决定。

---

# 11. 六维资质

每只宠物拥有：

- 生命资质
- 力量资质
- 灵力资质
- 防御资质
- 抗性资质
- 速度资质

范围：

> 0～100

评级建议：

| 数值 | 评级 |
|---|---|
| 90～100 | S |
| 80～89 | A |
| 70～79 | B |
| 60～69 | C |
| 50～59 | D |
| ＜50 | E |

同时计算一个：

> **综合资质评级**

综合评级仅作为快速筛选，不代表实际战斗强弱。

---

# 12. 资质作用

资质主要影响：

> **宠物升级时对应属性的固定成长。**

高资质不是直接增加大量即时属性。

设计目标：

> 资质差异应该在长期培养后逐渐体现，而不是刚捕获时就造成巨大差距。

自由属性点不受资质限制。

---

# 13. 稀有度

宠物种族稀有度固定。

共4档：

- 普通
- 稀有
- 珍稀
- 传说

例如某个种族如果属于“普通”，所有该种族个体都是普通。

不同个体品质通过：

- 六维资质
- 基础属性浮动
- 稀有技能
- 特殊外观

体现。

---

# 14. 稀有度设计原则

高稀有度主要意味着：

- 更特殊的技能机制
- 更优秀的属性分布
- 更具有特色的被动
- 少量额外自由属性点
- 更稀有的获取渠道

而不是：

> 单纯拥有远超普通宠物的总属性。

同等级、类似资质情况下，传说宠物不应该形成绝对数值碾压。

支持：

- 升1级
- 升5级
- 升到指定等级
- 升到当前阶段上限
- 自定义投入经验

- 所需经验
- 属性变化

- 新解锁被动技能

# 18. 等级上限与未来进化

第一阶段不实现进化。

但数据结构必须预留：

- 当前成长阶段
- 当前阶段等级上限
- 是否完成突破
- 下一阶段等级上限
- 进化目标
- 进化条件
- 进化模型
- 进化后技能
- 进化后成长

未来预计：

```text

↓
进化 / 突破
↓

```

Lv.50后必须完成未来的进化或突破，才能继续升级。

# 19. 自由属性点

所有宠物升级获得基础自由属性点。

默认方案：

> 每升1级获得3点。

稀有度提供少量阶段奖励。

建议：

| 稀有度 | 每级 | 每10级额外 |
|---|---:|---:|
| 普通 | 3 | 0 |
| 稀有 | 3 | 2 |
| 珍稀 | 3 | 4 |
| 传说 | 3 | 6 |

全部配置化。

---

# 20. 属性点转换

建议默认：

| 属性 | 消耗 |
|---|---|
| 生命 +5 | 1点 |
| 力量 +1 | 1点 |
| 灵力 +1 | 1点 |
| 防御 +1 | 1点 |
| 抗性 +1 | 1点 |
| 速度 +1 | 2点 |

速度成本较高，防止所有Build最终都只堆速度。

---

# 21. 加点规则

允许：

- 保存自由属性点不使用
- 一次批量分配
- 预览分配后属性
- 免费洗点
- 无硬性单项投入上限

第一阶段免费洗点，鼓励尝试不同Build。

升级、加点、洗点不能在战斗过程中操作。

升级或生命加点：

> 只增加最大HP，不恢复当前HP。

# 22. 技能体系

技能体系按「来源 × 类型」划分为四类：

| | 主动（ACTIVE） | 被动（PASSIVE） |
|---|---|---|
| 自身（INNATE） | 宠物自身主动技能 | 宠物自身被动技能 |
| 技能书（BOOK） | 技能书主动技能 | 技能书被动技能 |

### 宠物自身主动技能

第一阶段每只宠物种族自身最终拥有的主动技能，默认按照：

> **6个自身主动技能**

进行设计，并根据宠物定位允许少量浮动，正式设计范围为：

> **5～7个自身主动技能。**

- 简单普通宠物：5个左右；
- 大多数宠物：6个；
- 机制型宠物：6～7个；
- 少数珍稀、传说宠物：可以达到7个。

不能简单按照稀有度决定技能数量。高稀有度宠物的优势应主要体现在技能机制、被动机制、属性分布与战术特色，而不是单纯因为技能数量更多。

宠物已经掌握的自身主动技能，与战斗实际携带技能必须严格区分。战斗中：

> **最多装备4个宠物自身主动技能。**

例如某宠物已经掌握6个自身主动技能，进入战斗前从6个技能中选择4个装备；其余已掌握的技能永久保留，可以在非战斗状态下自由更换。战斗过程中禁止修改技能配置。

### 宠物固有被动技能

被动技能明确分为**固有被动**与**技能书被动**两大来源：

> **固有被动决定「它是谁」，技能书被动决定「你想把它培养成什么风格」。**

**固有被动**（宠物特色）：
- 来源：出生自带、升级自动获得、成长/进化获得、宠物特有或准专属能力；
- 职责：体现种族特色、战斗定位、元素特色、状态联动、战斗节奏、队伍作用、专属玩法；
- 生效：进入战斗后**全部自动生效**，不占主动技能槽、不需要装备、不需要战前选择、不设置战斗携带数量。

第一阶段每只宠物通常拥有：

> **默认约3～5个固有被动。**

内容设计建议范围 3～5 个：

- 简单普通宠物：3个；
- 标准宠物：3～4个；
- 机制型宠物：4个；
- 少数珍稀/传说宠物：4～5个。

每只宠物应至少拥有 **1个核心特色被动或准专属机制**（如残血爆发、反击、连击、状态联动、收割、护盾、治疗、生存、特殊元素机制等），用于建立宠物记忆点与区分度。允许同机制不同参数/触发条件/元素被少量宠物共享，但最终宠物间的实际玩法必须明显不同。固有被动数量通过内容设计控制，不由系统硬性限制。

### 标准宠物技能数量模板

为方便第一阶段27只宠物统一规划，采用标准模板：

> **6个自身主动技能 + 3～5个固有被动 ≈ 宠物自身技能。**

允许根据宠物定位少量调整：

- 简单普通宠物：5主动 + 2被动；
- 标准宠物：6主动 + 3被动；
- 机制型宠物：6～7主动 + 3～4被动；
- 少数珍稀/传说宠物：最多 7主动 + 4～5被动。

但不得形成「稀有度越高 = 技能数量越多 = 必然更强」的简单关系。

### 技能书主动技能

宠物可以通过技能书永久学习额外主动技能。

单只宠物：

> **最多永久学习10个技能书主动技能。**

战斗时：

> **最多装备2个技能书主动技能。**

因此单只宠物战斗中最多拥有：

> **4个自身主动技能 + 2个技能书主动技能 = 6个可主动释放技能。**

技能书主动技能规则：

- 不占宠物自身主动技能4槽；
- 学习后永久进入技能书技能库；
- 可以自由更换2个战斗携带技能；
- 不能在战斗过程中更换；
- 技能书主动技能达到10个后，再学习新技能需要选择遗忘一个已学习的技能书主动技能；
- 被遗忘技能如需重新学习，需要再次获得并消耗对应技能书。

### 技能书被动技能

技能书可以存在少量被动技能。**技能书被动**（玩家后天培养/Build 调整）：
- 不计入技能书主动技能10个学习上限；
- 不占2个技能书主动技能战斗槽；
- 属于**后天培养**，用于属性补强、战术微调、弱点补偿、定位强化，**不取代宠物核心特色**。

**关键规则：已学习 ≠ 当前生效。**

> **每只宠物最多同时启用 2 个技能书被动。**

- 学习后进入「已学习」状态，但**默认不启用**；
- 玩家可在战斗外从已学习的技能书被动中选择**最多2个**启用，其余保持「已学习未启用」；
- 可随时在战斗外启用/停用/替换；战斗过程中禁止修改；
- 技能书学习数量与生效数量分离：学习数量沿用现有规则，生效数量受2槽限制。

系统不设置技能书被动学习数量上限，但内容设计层面必须保持克制：大部分技能书仍应设计为主动技能，被动技能书数量较少（第一阶段约10种），可通过元素限制、战斗定位限制、指定宠物限制、特定获取方式避免所有宠物最终启用完全一致的被动。

### 被动技能通用规则

> **固有被动 + 技能书被动分开管理。**

- **固有被动**：全部自动生效，不占槽位、不可卸下。
- **技能书被动**：已学习 ≠ 当前生效，最多启用 2 个（槽位独立于主动技能槽）。

**重复规则：**

> **同名/同效果被动不能重复生效。**

- 固有被动与技能书被动同名（如固有「迅捷」+ 技能书「迅捷」）时，只生效一次，取更高效果；
- 不同名称但效果相近的被动通过**效果组（effectGroup）+ 叠加规则（stackRule）**处理（如 UNIQUE / HIGHEST_ONLY / ADDITIVE+上限），避免数值膨胀。

**防循环：** 反伤不触发反伤、被动伤害不无限触发攻击被动、治疗被动不无限触发治疗被动、换宠被动不造成换宠循环、额外行动不造成无限行动。

# 23. 技能获取

第一阶段主要通过：

### 等级解锁

达到对应等级自动学会。

升级自动掌握自身技能，不需要消耗金币、技能点、技能经验、技能熟练度或技能升级材料。第一阶段不设计技能等级，技能一旦通过等级解锁即直接获得完整技能效果；未来如需要增加技能强化，作为后续阶段设计。

### 稀有技能

部分野生个体低概率自带。

### 技能书

部分技能可以通过技能书学习。

技能数据必须区分两个独立维度：

### 技能来源

- `INNATE`（自身）
- `BOOK`（技能书）
- 后续预留 `EVOLUTION`、`SPECIAL`

### 技能类型

- `ACTIVE`（主动）
- `PASSIVE`（被动）

例如：

- 【留生一击】：BOOK + ACTIVE
- 【余烬】：INNATE + PASSIVE
- 【汲血本能】：BOOK + PASSIVE

不得使用一个字段同时承担“来源”和“主动/被动”两个概念。

---

# 24. 技能稀有度

技能分：

- 普通
- 稀有
- 专属

专属技能通常只属于少数宠物。

---

# 25. 技能属性系数

技能效果必须支持：

> **基础数值 + 一个或多个宠物属性系数**

例如：

```text
烈焰爪

基础伤害：50
力量系数：1.25

伤害基础值 =
50 + 1.25 × 力量
```

也允许：

```text
疾风斩

35
+ 0.8 × 力量
+ 0.6 × 速度
```

治疗：

```text
30 + 1.2 × 灵力
```

护盾：

```text
50 + 1.5 × 防御
```

技能配置应支持多个属性系数组合。

也允许取两个属性中较高者参与计算：

```text
基础值 + 系数 × MAX(力量, 灵力)
```

用于让力量型和灵力型宠物都能正常使用的通用技能（如【留生一击】）。

---

# 26. 主动技能类型

第一阶段支持：

- 单体攻击
- 群体攻击
- 治疗
- 护盾
- 增益
- 减益
- 控制
- 状态
- 蓄力技能

目标类型支持：

- 敌方单体
- 敌方全体
- 己方单体
- 己方全体
- 自身

---

# 27. 技能资源机制

第一阶段：

> **不设置MP/蓝量。**

技能主要通过：

> **冷却时间**

限制使用。

例如：

- 基础技能：0冷却
- 常规强力技能：1～2回合
- 群攻/强治疗：2～3回合
- 强力技能：3～4回合
- 改变战斗规则的特殊技能（如【命运天平】）：4～5回合

每只宠物技能冷却独立计算。

配置层预留：

> `maxUsesPerBattle`

用于限制少数特殊技能每场战斗的成功使用次数，第一阶段默认不启用，由数值测试决定。

---

# 28. 技能配置原则

允许：

- 宠物拥有少量跨属性技能
- 高级技能包含多个效果
- 技能之间产生少量状态联动
- 被动改变主动技能机制
- 少量技能需要蓄力

不做复杂元素反应网络。

---

# 29. 状态体系

第一阶段使用的状态包括：

持续伤害类：

- 灼烧
- 中毒

控制类：

- 麻痹
- 缠绕
- 致盲
- 沉默
- 震慑

元素特色与增减益Debuff：

- 浸湿
- 破甲
- 诅咒
- 嘲讽

第一阶段优先新增机制：

1. **混乱**
2. **反击**
3. **再生**
4. **狂暴**
5. **隐匿**
6. **标记**

不继续无上限扩充。

状态效果配置化。新增状态与特殊技能机制的具体规则见本文档第142～148节（技能与状态体系补充）。

---

# 30. 状态联动

允许少量直观联动，例如：

```text
目标处于浸湿
+
受到雷属性技能
=
伤害提高
```

或者：

```text
目标处于灼烧
+
部分风系技能
=
扩散或强化灼烧
```

联动数量保持有限。

---

# 31. 被动技能

被动尽量采用机制型设计。

例如：

**顺风**

> 登场后全队速度提升1回合。

**不屈**

> 第一次受到致命伤害时保留1点生命。

**余烬**

> 倒下时对敌方造成火属性效果。

**岩甲**

> 高生命状态下护盾效果增强。

支持触发时机：

- 登场
- 退场
- 受击
- 攻击
- 暴击
- 击败
- 倒下
- 回合开始
- 回合结束
- 战斗开始
- 战斗结束
- 行动前
- 造成伤害前/后
- 治疗后
- 释放技能后
- 状态被附加时
- 友方倒下

---

# 32. 战斗模式

采用：

> **队伍式回合制**

玩家：

> 最多携带6只宠物。

标准战斗：

> 同时上场3只。

底层预留：

> 特殊玩法最多支持4只上场。

第一阶段标准玩法固定3只。

---

# 33. 战斗队伍

```text
首发：
宠物A
宠物B
宠物C

候补：
宠物D
宠物E
宠物F
```

全部6只失去战斗能力：

> 战斗失败。

---

# 34. 回合行动

每个回合：

1. 玩家为3只宠物选择行动；
2. AI选择行动；
3. 根据速度排列所有宠物行动顺序；
4. 依次执行；
5. 结算状态；
6. 进入下一回合。

每只存活上场宠物：

> 每回合拥有一次行动。

---

# 35. 行动顺序

主要根据：

> **速度**

从高到低行动。

速度相同时：

> 随机决定先后。

技能和Buff可以改变速度，因此每回合重新计算。

---

# 36. 战斗基础行动

宠物可以：

- 使用主动技能
- 替换宠物
- 防御
- 使用道具（**桌面重构裁决：探索背包与战斗背包共享库存；战斗内只允许服务端配置 `usableInBattle=true` 的恢复/复苏道具，捕捉球继续走捕捉行动；旧“战斗内无道具行动”结论已由 R-043 覆盖**）

野外战斗额外允许：

- 捕捉
- 逃跑

---

# 37. 换宠

主动换宠：

> 消耗该宠物当前回合行动。

新宠物立即进入原位置，并可能承受该回合后续攻击。

某只宠物失去战斗能力：

> 当前行动结算完成后进行候补补位。

补位不消耗下一回合行动。

允许少量换宠类技能（如【风返】【援护召回】，见第146节）：

> 使用技能本身就是该宠物本回合行动，后续换宠不再额外消耗另一份行动。

规则需与主动换宠保持一致。

---

# 38. 嘲讽与保护

支持：

### 嘲讽

影响敌方单体技能目标。

### 援护

替指定队友承担部分单体伤害。

群体技能原则上不受嘲讽影响。

---

# 39. 暴击

基础暴击率建议：

> **5%**

允许技能、被动提高。

暴击伤害倍率：

> **1.4～2.0随机**

默认采用均匀随机。

例如：

```text
正常最终伤害 = 100

暴击可能产生：
142
167
189
200
```

治疗第一阶段不能暴击。

---

# 40. 命中

技能可配置：

> 命中率。

例如：

- 稳定技能：100%
- 强力技能：85%～95%
- 强控制技能：70%～90%

致盲等状态可影响命中。

---

# 41. 伤害结算顺序

建议统一为：

```text
技能基础值
+
属性系数
↓
防御 / 抗性计算
↓
属性克制
↓
本属性加成
↓
Buff / Debuff
↓
暴击
↓
最终伤害
```

正常命中的伤害技能：

> 最低造成1点伤害。

物理型主要受防御影响。

灵力/元素型主要受抗性影响。

具体减伤公式配置化。

---

# 42. 护盾

护盾值可以使用属性公式。

例如：

```text
50 + 防御 ×1.5
```

护盾被攻击时，不再次套用宠物防御计算，避免双重减伤。

---

# 43. Boss控制抗性

Boss不会完全免疫异常。

建议默认：

- 普通敌人：正常
- 精英：异常成功率约降低20%
- Boss：约降低40%

连续控制增加衰减。

建议：

```text
第一次：×1.0
第二次：×0.7
第三次：×0.4
```

具体参数配置化。

---

# 44. 战败

玩家战败：

- 不扣金币
- 不扣经验
- 不掉物品
- 不丢宠物

退出当前战斗并返回最近恢复点。

队伍恢复。

增加轻度嘲讽式提示，例如：

> “看来这支队伍还需要再磨合一下。”

不产生实际惩罚。

---

# 45. 普通战斗持续性

普通地图探索中：

> 战斗结束后HP不自动恢复。

如果某只宠物在胜利战斗中失去战斗能力：

> 战斗后仍保持0HP。

需要：

- 药品
- 复苏道具
- 营地

恢复。

技能冷却、Buff、Debuff、异常状态原则上不跨战斗保留。

---

# 46. 捕捉

野生宠物必须通过战斗捕捉。

影响捕捉概率：

- 宠物基础捕获率
- 当前剩余HP
- 异常状态
- 捕捉球倍率

第一阶段不增加过多额外修正。

【震慑】状态仅提供安全捕捉窗口：

> 不额外提高捕获概率。

捕捉公式不添加文档之外的修正项（见第142节）。

---

# 47. 捕获概率显示

使用捕捉道具前：

> **直接显示具体成功率。**

例如：

```text
普通捕捉球：37.6%
高级捕捉球：52.3%
特级捕捉球：68.1%
```

宠物状态改变后实时更新。

---

# 48. 捕捉球

第一阶段仅3档：

1. 普通捕捉球
2. 高级捕捉球
3. 特级捕捉球

普通球价格较低，鼓励放心捕捉。

捕捉失败：

> 捕捉球被消耗。

---

# 49. 多宠物遭遇捕捉

一次遭遇可以捕捉多只宠物。

捕捉成功后：

> 该宠物立即退出敌方队伍。

其余敌人继续战斗。

新捕捉宠物：

> 不能加入当前战斗。

---

# 50. 捕捉与掉落

被捕捉宠物：

> 不获得对应的击败掉落。

例如3只敌人：

- 捕捉1只
- 击败2只

只结算2只被击败宠物的掉落。

---

# 51. 宠物仓库

宠物仓库：

> **不限制容量。**

队伍未满6只时，捕捉成功可以选择直接加入队伍。

否则进入仓库。

---

# 52. 宠物仓库筛选

支持：

- 名称
- 属性
- 稀有度
- 等级
- 综合资质
- 稀有技能
- 特殊外观
- 收藏
- 锁定
- 是否在队伍

排序：

- 等级
- 稀有度
- 综合资质
- 捕获时间

---

# 53. 宠物锁定和收藏

宠物可：

- 锁定
- 收藏

锁定后禁止放生。

珍稀、传说、高资质、稀有技能、特殊外观宠物放生时需要额外警告。

---

# 54. 批量放生

支持批量选择宠物放生。

自动排除：

- 锁定宠物
- 收藏宠物
- 当前队伍宠物

放生后汇总所有宠物赠送的资源。

---

# 55. 放生临别礼物

放生不表现为“分解”。

表现为：

> **宠物离开前送给玩家的临别礼物。**

例如：

> “烬牙兽准备重新回到原野生活。离开前，它留下了一些珍藏的东西。”

礼物：

- 类型随机
- 数量随机
- 至少具有实际价值
- 不允许出现明显过低奖励

---

# 56. 放生奖励影响因素

主要根据：

1. 宠物种族稀有度
2. 捕获时等级

玩家后续人为培养等级：

> 可以提高奖励，但增幅较小。

最大：

> **在原有价值基础上上浮50%。**

避免：

```text
经验池
→ 强行升级宠物
→ 放生
→ 无限转换高价值资源
```

---

# 57. 特殊个体

第一阶段支持：

### 精英个体

地图偶尔出现。

特点：

- 等级较高
- 最低资质更高
- 稀有技能概率更高
- 捕捉难度更高
- 地图上带特殊标识

### 特殊外观

极低概率出现不同外观。

不提供额外属性。

纯收藏价值。

第一阶段不做“变异”系统。

---

# 58. 宠物昵称

玩家可以给拥有的宠物设置昵称。

同时始终保留种族名称。

# 66. 自动战斗

支持自动战斗。

规则：

> **只有玩家已经成功击败过的敌人才允许自动战斗。**

包括：

- 普通怪
- 精英怪
- Boss
- 特殊敌人

Boss不同难度、不同变体：

> 必须分别手动通关一次。

# 67. 自动战斗策略

提供轻量预设：

- 均衡
- 进攻
- 稳健
- 捕捉

宠物可设置简单定位：

- 输出
- 坦克
- 辅助
- 控制

支持：

- 自动换宠开关
- 自动使用恢复道具开关
- 自动复苏开关
- HP阈值设置

默认：

> 自动使用消耗道具关闭。

自动AI需要认识技能语义标签，主要根据：

> 标签 + 当前战斗状态

进行选择，不需要真正理解所有技能脚本。标签包括：

- DAMAGE
- HEAL
- CONTROL
- CAPTURE_ASSIST
- SURVIVAL
- FINISHER
- SHIELD_BREAK
- DISPEL
- SWITCH
- ACTION_ORDER
- LIFE_STEAL

捕捉策略规则：

- 目标可捕捉且HP较高时，正常降低生命；
- 普通高伤害技能存在误杀风险时，优先使用【留生一击】；
- 目标已被压到1HP并附加震慑时，优先捕捉，不再继续攻击。

自动AI默认不频繁使用【命运天平】，仅在满足明显收益条件（自身HP明显低于目标、交换后不造成明显战术劣势、Boss交换收益达到阈值）时才考虑，避免随机使用后反而给敌人回血。

# 83. Boss幸运值

每个Boss拥有独立幸运值。

不同难度共享该Boss幸运值。

例如：

- 普通：+4
- 困难：+7
- 噩梦：+10

具体值配置化。

---

# 84. 幸运值不封顶

例如：

```text
幸运值：245

可兑换次数：2
剩余幸运值：45
```

每100幸运值：

> 可兑换一次。

正常随机掉落不会清空幸运值。

---

# 85. 幸运值兑换

幸运值满后：

> 可以从该Boss已经公开的掉落池中任选一种奖励。

只能兑换：

> 该Boss自身能够掉落的物品。

低价值物品：

> 一次兑换数量较多。

高价值：

> 数量较少。

例如：

| 奖励 | 兑换数量 |
|---|---:|
| 属性材料 | ×30 |
| 高级捕捉球 | ×15 |
| Boss核心 | ×8 |
| 稀有技能书 | ×2 |
| 珍稀宠物核心 | ×1 |

同一奖励允许重复兑换。

---

# 86. Boss掉落情报

Boss首次出现：

- 普通掉落公开
- 高级掉落显示 `???`

成功击败：

### 3次

> 解锁全部稀有掉落。

### 6次

> 解锁全部珍稀掉落。

### 10次

> 解锁完整掉落池。

如果提前获得隐藏物品：

> 该物品立即解锁。

# 87. Boss自动重复挑战

已经手动击败对应难度后支持：

- 自动挑战1次
- 自动挑战5次
- 自动挑战10次
- 持续挑战直到失败
- 持续挑战直到满足下一次幸运兑换条件

每场战斗真实执行，不是扫荡。

失败：

> 自动停止。

---

# 88. Boss重复战恢复

Boss重复挑战：

> 每场视为独立战斗。

战斗结束后：

> 下一场开始前自动恢复全队。

地图普通探索仍然保留HP连续消耗。

# 89. Boss掉落结算

连续挑战采用：

> 汇总结算。

例如：

```text
挑战：10
成功：10

经验池 +12500
金币 +8600
雷之结晶 ×31
Boss核心 ×7
稀有技能书 ×1

幸运值：
73 → 143
```

珍稀/传说掉落需要单独醒目标识。

# 96. 技能书

技能书：

> 一次性消耗。

学习后技能永久进入宠物技能库。

存在学习限制。

不是所有宠物都能学习所有技能。

专属技能不能通过普通技能书学习。

技能书主动技能学习上限：

> **单只宠物最多永久学习10个技能书主动技能。**

战斗携带上限：

> **最多装备2个技能书主动技能。**

达到学习上限后再学习新技能，需要选择遗忘一个已学习的技能书主动技能；被遗忘技能如需重新学习，需要再次获得并消耗对应技能书。

技能书被动不计入主动技能学习上限，也不占战斗携带槽，掌握后自动生效。

技能书不要全部设计成“所有宠物可学习”，除【留生一击】等通用技能外，其他技能书可按属性、战斗定位、宠物种族、稀有度或指定名单限制。

### 第二优先级

### 第四优先级

> 操作简单、开发可控。

# 141. 第一阶段最终产品目标

第一阶段完成后，玩家应能够获得完整体验：

> 从一个初始宠物开始，在多个区域探索，捕获27种不同属性和定位的元素宠物；通过公共经验池培养喜欢的宠物，自由分配属性和组合技能；组成6宠队伍并进行3宠同时上场的回合制战斗；利用速度、属性克制、换宠、控制、治疗和技能联动挑战不同Boss；通过Boss多难度、幸运值、图鉴、高资质个体、稀有技能和特殊外观形成持续游玩目标。

整个第一阶段应保持：

> **内容完整、机制清晰、能够长期自己玩，但不为了“像大型商业游戏”而增加不必要复杂度。**

# 142. 技能与状态体系补充：留生一击与震慑

本节为第一阶段技能体系与战斗状态体系的正式补充，与前述章节具有同等效力。

## 142.1 通用捕获技能：留生一击

正式增加第一阶段最重要的通用捕获辅助技能：

> **留生一击**

基础规则：

- 主动技能，技能书技能（BOOK + ACTIVE）；
- 无属性、单体；
- 所有宠物可学习；
- 冷却0；
- 基础命中100%；
- 可以暴击；
- 不参与属性克制；
- 不享受本属性1.2倍加成；
- 不附带普通元素异常。

伤害强度与普通零冷却基础技能接近，建议公式：

```text
50 + 1.0 × MAX(力量, 灵力)
```

具体数值必须配置化。

## 142.2 不致死机制

如果技能正常计算伤害不足以击败目标：

> 正常造成伤害。

如果正常伤害足以让可捕捉目标失去战斗能力：

> 将目标最终HP保留为1。

例如目标93HP、理论伤害178，实际结果为 `93 → 1`。即使产生暴击也不能绕过此规则。

## 142.3 持续伤害处理

仅当技能实际触发“目标保留1HP”时，立即清除目标身上的持续伤害状态：

- 清除：灼烧、中毒及其他会继续直接扣除HP的持续伤害状态；
- 不清除：麻痹、缠绕、致盲、沉默、减速、Buff、Debuff及其他非持续生命伤害状态。

普通命中但没有触发1HP保护时，不清除任何状态。

## 142.4 专属状态：震慑

当【留生一击】真正触发“目标保留1HP”且目标属于可捕捉野生宠物时，自动附加：

> **震慑**

震慑效果：

> 目标在接下来的一个行动周期内无法主动行动，为玩家提供一次安全捕捉机会。

持续规则按BattleEngine状态持续规则实现：

> 确保目标至少失去下一次原本能够执行的主动行动。

震慑期间：

- 可以被捕捉；
- 可以受到技能；
- 可以被换目标；
- 不能主动释放技能；
- 不会额外提高捕获概率。

震慑的意义是提供安全捕捉窗口，而不是进一步提高数值捕获率。

目标已经处于1HP时再次使用留生一击，由于没有再次发生真正的“致死伤害 → 保留1HP”，不得无限刷新震慑。

## 142.5 Boss与留生一击

Boss不可直接捕捉：

- 留生一击仍然可以对Boss造成正常伤害；
- 可以保留Boss最后1HP；
- **不可捕捉Boss不附加捕获专用的震慑效果。**

避免通用捕捉技能变成Boss战稳定强控制。

## 142.6 获取方式

增加：

> **技能书·留生一击**

规则：

- 普通商店常驻；
- 前期即可购买；
- 价格较低；
- 不使用特殊材料；
- 不需要Boss掉落；
- 不限制属性与稀有度；
- 所有宠物均可学习。

第一次捕捉教学免费赠送1本，让玩家很早就知道游戏支持专门的捕获辅助技能。

# 143. 技能与状态体系补充：吸血机制

增加通用技能效果：

> **吸血 / Life Steal**

伤害技能可以配置：

> 本次实际生命伤害的X%转化为自身HP恢复。

例如伤害200、吸血30%，则恢复60HP。

## 143.1 按实际HP损失计算

吸血不能根据理论伤害计算。例如目标护盾100、HP500，技能造成250伤害，其中100被护盾吸收、实际HP损失150，30%吸血恢复45。

## 143.2 过量伤害不计算吸血

目标剩余50HP、攻击计算300，最终只能造成50点实际生命损失，30%吸血只能恢复15，不能根据300伤害恢复90。

## 143.3 其他规则

默认：

- 暴击可以因为提高实际伤害而间接增加吸血；
- 吸血不能超过最大HP，溢出的治疗直接丢弃，不自动转化为护盾；
- DOT默认不吸血；
- 反击默认不吸血；
- 反射伤害默认不吸血；
- 普通被动伤害默认不吸血；
- 吸血受到禁疗和治疗效果降低影响。

未来少数专属技能可以明确“DOT允许吸血”，但第一阶段默认关闭。

## 143.4 适合吸血的属性

吸血主要用于：

- **暗**：灵魂汲取、生命吞噬、噬魂、残血反杀；
- **木**：可少量设计，如根须汲取、生命循环、自然吸收；
- **火**：只允许少量高风险狂战类吸血。

不要让所有属性普遍拥有大量吸血技能。

# 144. 技能与状态体系补充：新增状态规则

在现有灼烧、中毒、麻痹、缠绕、致盲、沉默、浸湿、破甲、诅咒、嘲讽、震慑基础上，第一阶段新增以下六个优先机制，不继续无上限扩充。

## 144.1 混乱

核心特色：

> 敌我识别出现异常。

不简单设计成“概率不能行动”，避免与麻痹重复。

- 单体攻击技能：原本目标可能被重新随机指定，可攻击敌方或友方；默认在除施法者自身之外的场上合法存活单位中随机重新选择，自身是否允许由技能规则明确；
- 单体治疗/单体Buff：混乱时也可能错误作用到其他合法单位；
- 群体技能：第一阶段不改变阵营目标，否则3V3中规则过于混乱；
- 自身技能：正常作用自身。

混乱一般持续1～2回合，不能无限叠加持续时间；再次附加只刷新到该状态允许的最大持续时间。

## 144.2 反击

用于金、土等防御型宠物。示例【荆岩甲】：持续2回合，受到敌方直接单体主动技能伤害后，对攻击者进行一次反击。反击伤害可根据防御、力量、最大生命计算。

默认：

- 群攻不触发；
- DOT不触发；
- 反击不能再次触发反击，防止无限递归。

## 144.3 再生

示例【生命萌芽】：持续3回合，每回合结束恢复一定生命。

与普通治疗的区别：普通治疗解决立即危机，再生提供持续续航。适合木、水、少量光。再生属于治疗，受到禁疗效果影响。

## 144.4 狂暴

典型形式：提高输出，同时降低防御能力。示例【焚心】持续3回合：力量提高、防御降低，或暴击提高、受到伤害提高。主要适合火、暗等高风险Build。

狂暴必须体现“收益 + 代价”，不要只是另一个普通攻击Buff。

## 144.5 隐匿

主要适合风、暗。规则：

- 不能成为普通敌方单体主动技能的直接目标；
- 群体技能仍然可以命中；
- 自己主动攻击后解除隐匿；
- 某些技能可以明确“无视隐匿”。

避免隐匿成为无敌。

## 144.6 标记

用于团队组合。示例：

- 【猎杀印记】：目标持续2回合，受到物理伤害提高一定比例；
- 【雷印】：可叠加层数，达到指定层数后触发额外效果。

标记的设计目的是让不同宠物之间自然形成技能组合，不增加单独的“连携技能按钮”。

# 145. 技能与状态体系补充：少量高级技能机制

以下机制仅给少数珍稀或专属技能使用，不需要全部做成全局常见状态。

## 145.1 破盾

设计对护盾造成额外伤害的技能。示例【裂甲重击】：对HP正常伤害；对护盾伤害×2；如果击破护盾，可以额外附加短暂破甲。让护盾拥有明确克制手段。

## 145.2 驱散与偷取Buff

- 驱散：移除目标指定数量的正面Buff；
- 偷取：示例【暗影窃取】，移除目标1个可偷取Buff并复制给自己。

Boss阶段Buff、剧情Buff等可以配置 `dispellable = false`，避免Boss核心机制被一个技能直接移除。

## 145.3 残血强化

适合火、暗。示例：

- 【绝境斩】：自身HP低于30%时，本技能伤害额外提高；
- 【背水】（被动）：当前HP百分比越低，力量越高。

残血强化必须存在明确上限，不得无限增长。

## 145.4 行动顺序干预

3V3战斗的重要特色之一，允许少量风系技能：

- 提前行动：示例【疾风牵引】，让一个队友本回合的行动位置提前；
- 延后行动：示例【迟滞】，让目标本回合行动位置延后。

这是当前回合行动顺序操作，不直接改变基础速度永久值，必须与普通速度Buff区分。

## 145.5 叠层技能

层数型状态。示例【雷印】：每次指定技能命中+1层，达到3层自动触发雷爆，触发后清空层数。第一阶段只给极少数状态使用叠层。

## 145.6 延迟效果

允许技能生成若干回合后自动触发的效果。示例：

- 【星陨】：对敌方放置星印，2回合后造成高额伤害；
- 【生命之种】：2回合后恢复大量生命。

延迟效果应让玩家能够提前防御、换宠、净化、护盾，做出对应决策。

## 145.7 连锁攻击

示例【连锁闪电】：攻击主要目标后自动弹射到其他敌人，每次弹射伤害逐渐衰减（如100% → 70% → 50%）。适合雷属性，与普通全体技能形成区别。

## 145.8 溅射攻击

主目标承受完整伤害，其他敌人受到部分伤害。示例【震地重击】：主目标100%、其他目标30%。可用于土、金、火。

## 145.9 禁疗

> **禁疗属于Debuff。**

可以完全阻止治疗，或降低一定比例治疗效果。第一阶段建议多数技能使用治疗效果降低，完全禁疗作为少数强力技能。

禁疗同时影响直接治疗、再生、吸血与其他HP恢复。

## 145.10 治疗溢出转护盾

允许少量珍稀技能将治疗超过最大HP的部分按一定比例转为护盾（示例【溢光】：溢出部分50%转化为护盾）。默认普通治疗仍然直接丢弃溢出量。这是特殊技能能力，不是全局规则。

## 145.11 技能封锁 / 冷却操作

除沉默外增加更温和的技能干扰。示例【封技】：将目标刚刚使用过的一个技能额外增加若干回合冷却。这比完全不能释放技能更有战术性。

# 146. 技能与状态体系补充：换宠技能与登退场机制

## 146.1 换宠技能

重点增加少量利用6宠队伍的战术技能：

- 【风返】：对敌人造成伤害后，自身退场，并由指定候补宠物进入原位置；
- 【援护召回】：将低血友方换回候补，由施法者或指定候补替换进入。

这类技能：

> 使用技能本身就是该宠物本回合行动，后续换宠不再额外消耗另一份行动。

需要与现有主动换宠规则保持一致。

## 146.2 登场 / 退场机制

允许少量被动：

### 登场触发

- 【雷袭】：登场时对随机敌方造成少量伤害；
- 【大地守护】：登场时给友方全体提供小护盾；
- 【清风】：登场时清除自身一个Debuff。

### 退场触发

例如：主动换下时为下一只宠物提供速度Buff。

这让6宠编队真正成为战斗体系的一部分，而不是3只死亡后的备用血条。

# 147. 技能与状态体系补充：命运天平与生命操作技能

## 147.1 命运天平

加入少量直接改变战斗规则的高级技能，代表技能：

> **命运天平**

核心机制：

> 使用者与目标交换双方当前HP百分比。

例如A `100/1000 = 10%`、B `1800/2000 = 90%`，交换后A `900/1000`、B `200/2000`。交换的是HP百分比，不是具体HP数值。

## 147.2 命运天平不是伤害

HP交换必须作为独立效果，它：

- 不是伤害；
- 不是治疗；
- 不触发暴击；
- 不触发吸血；
- 不触发反击；
- 不受防御影响；
- 不受抗性影响；
- 不受护盾影响；
- 不参与属性克制；
- 不触发“受到伤害时”被动；
- 不计入总伤害统计。

护盾保持原值，不参与交换；Buff、Debuff、状态不进行交换。

## 147.3 与普通敌人

普通可捕捉宠物可以正常交换HP比例，可以形成高风险捕获Build（自己保持低HP → 交换 → 把野生宠物压到低HP → 捕捉）。这是允许的策略玩法。

但【命运天平】不清除DOT、不附加震慑、不直接增加捕获概率，与【留生一击】形成不同定位。

## 147.4 与Boss

Boss不允许完整比例交换，否则Boss数值体系会失效。采用交换幅度上限而不是完全免疫：

```text
bossHpExchangeLimit = 0.20
```

含义：单次最多改变Boss 20个百分点HP比例。例如玩家10%、Boss90%，理论完整交换后玩家90%、Boss10%，实际受20%限制后玩家约30%、Boss约70%。具体计算方式在技术设计中明确，并配置化。精英也可以预留独立限制参数。

## 147.5 冷却

这类改变HP结构的技能属于珍稀/专属战术技能，冷却应明显高于普通技能，建议4～5回合。配置层提前支持 `maxUsesPerBattle`，未来如果测试发现循环交换过强，可以改为每场战斗最多成功使用一次。第一阶段先通过数值测试决定最终值。

## 147.6 少量同类生命操作技能

可以围绕命运天平进一步增加少量同类技能，但不要泛滥：

- 【生命均衡】：将己方存活宠物当前HP百分比重新平均分配（如90%/30%/30% → 约50%/50%/50%），适合光系珍稀辅助；
- 【血契】：消耗自身一定生命，为队友恢复生命，适合暗/光/木；
- 【生命守望】（濒死保护）：给友方附加一次性保护，如果本次伤害将其击败，则保留1HP并消耗状态；与留生一击一个用于敌方捕获、一个用于友方保护。

# 148. 技能与状态体系补充：配置能力、自动战斗与内容规模

## 148.1 技能设计与九属性特色结合

扩充技能时优先保持以下属性倾向（不是严格职业限制）：

| 属性 | 特色倾向 |
|---|---|
| 金 | 破甲、破盾、物理爆发、标记、反击 |
| 木 | 再生、缠绕、中毒、生命汲取、延迟治疗 |
| 水 | 浸湿、减速、治疗、净化、控制 |
| 火 | 灼烧、狂暴、残血爆发、生命代价、高风险高收益 |
| 土 | 护盾、嘲讽、援护、反击、防御系数攻击 |
| 风 | 速度、行动顺序、隐匿、换宠、登退场 |
| 雷 | 高速爆发、麻痹、雷印、连锁攻击、浸湿联动 |
| 光 | 治疗、净化、Buff、濒死保护、生命均衡、溢出治疗转护盾 |
| 暗 | 诅咒、混乱、禁疗、吸血、偷取Buff、残血收割、命运天平 |

## 148.2 状态模型统一要求

BattleEngine状态体系至少区分：

- 持续状态：灼烧、中毒、混乱、隐匿、狂暴、再生等；
- Buff：力量提高、速度提高、护盾强化等；
- Debuff：防御降低、禁疗、命中降低、破甲等；
- 特殊控制：麻痹、缠绕、沉默、震慑；
- 标记：雷印、猎杀印记等。

不要所有东西都塞到一个简单的 `statusType` 然后大量if/else判断。

## 148.3 禁止技能ID硬编码

不得出现按技能ID判断特殊逻辑的写法，应判断效果类型及其配置。例如【留生一击】可由“伤害 + 保留1HP + 清除持续伤害 + 附加捕获震慑”的效果组合实现，【命运天平】使用HP百分比交换效果。以后新增类似技能不用修改BattleEngine主体。具体效果能力清单见技术方案文档。

## 148.4 内容规模控制

即使增加以上机制，第一阶段仍然保持：

> **约80～100个技能配置。**

不要因为增加机制将第一阶段扩大到200～300个技能。设计方法：

```text
有限效果
+
不同数值
+
不同属性
+
不同目标
+
不同状态组合
=
大量有差异的技能
```

27只宠物不要求每只拥有完全独立的底层机制，可以共享普通技能、元素技能、状态技能，再给每只宠物至少1个明显具有自身特色的核心技能或被动。

## 148.5 测试要求

第一阶段新增机制至少补充以下测试：

### 留生一击

非致死；致死；暴击致死；1HP目标；灼烧目标；中毒目标；麻痹+灼烧；震慑持续；再次留生不能无限刷新；Boss不触发捕获震慑；自动捕捉正确使用。

### 吸血

普通伤害；暴击；护盾；过量伤害；满血；禁疗；DOT默认不吸血；反击默认不吸血。

### 混乱

单体攻击改目标；单体治疗改目标；群攻正常；自身技能正常；持续时间；Boss控制抗性；不发生非法目标。

### 反击

单体攻击触发；群攻规则；DOT不触发；反击不触发反击；宠物倒下时规则。

### 隐匿

单体无法选中；群体仍命中；攻击后解除；无视隐匿技能。

### 标记 / 叠层

层数增加；最大层数；达到层数触发；清空；换宠后的保留规则。

### 换宠技能

技能执行；离场；候补登场；登场被动；行动权；倒下处理。

### 命运天平

相同最大HP；不同最大HP；护盾；Buff/Debuff；普通敌人；可捕捉敌人；精英；Boss交换上限；不触发吸血；不触发反击；不计算伤害；DOT不被清除。

## 148.6 补充设计底线

本次补充不推翻：9属性、27宠物、6宠队伍、3只同时上场、公共经验池、六维资质、自由属性点、Boss系统、图鉴、单机本地部署、单JAR发布等既有设计。

最终设计应做到：

> **普通宠物容易理解，珍稀宠物具有特色，传说宠物拥有少量改变规则的能力；技能系统有策略深度，但仍然适合一个人开发、测试和长期维护。**

# 149. 技能池分层与技能共享

## 149.1 不同宠物允许共享技能

正式明确：不同宠物允许共享部分主动技能和被动技能。第一阶段不要求27只宠物全部拥有完全独立的技能，技能共享属于正式设计方案。

目的包括：

1. 控制技能配置总量；
2. 降低开发成本；
3. 降低测试成本；
4. 降低玩家学习成本；
5. 建立元素技能认知；
6. 建立战斗定位认知；
7. 方便后续继续增加宠物；
8. 避免制造大量只有名称不同、数值略有不同的重复技能。

不同宠物即使拥有部分相同技能，只要属性成长不同、技能组合不同、被动不同、定位不同、专属技能不同，仍然可以形成完全不同的战斗体验。

被动技能同样允许共享（例如【火焰亲和】可由多个火属性宠物掌握，【反击本能】可由部分金、土属性宠物共享，【再生本能】可由部分木、水属性宠物共享），但每只宠物仍必须拥有至少1个明显属于自身玩法特色的被动或核心机制。

## 149.2 技能池分层

第一阶段技能体系划分为四个层级：

### 1. 通用 / 基础技能

允许多个不同元素宠物共享，例如基础攻击类、基础防御类、少量简单辅助技能，数量保持较少。

> 注意：【留生一击】属于技能书主动技能体系，不计入宠物自身通用技能数量。

### 2. 元素共享技能

同一元素的多个宠物可以共享部分技能。例如火属性技能池可以包含火焰攻击、灼烧攻击、火球、炎爆、狂暴类技能；火属性3只宠物不要求每一只都拥有完全不同的火属性技能。同样规则适用于金、木、水、火、土、风、雷、光、暗全部九属性。

### 3. 定位 / 机制共享技能

不同属性但拥有类似战斗定位的宠物，允许共享部分机制技能：

- 坦克型：嘲讽、援护、护盾、反击；
- 治疗型：单体治疗、再生、净化；
- 高速型：速度强化、行动提前、换宠技能；
- 控制型：减速、标记、部分控制技能。

允许跨元素少量共享，但不能因为大量共享而破坏九属性本身的战斗特色。

### 4. 宠物特色 / 专属技能

每只宠物必须拥有少量真正体现自身特色的技能（见 149.3）。

## 149.3 特色 / 专属技能最低要求

每只宠物至少拥有：

> **1个明显特色主动技能 + 至少1个明显具有自身特色的被动技能或核心机制。**

推荐大多数宠物拥有 1～2个特色主动技能 + 1个特色被动技能。专属技能的作用：建立宠物记忆点、区分同元素3只宠物、强化战斗定位、形成不同Build、形成独特战斗节奏。

## 149.4 共享技能比例参考

标准宠物拥有6个自身主动技能时，推荐组成大致为：

- 1个基础 / 通用技能；
- 2个左右元素共享技能；
- 1～2个定位 / 机制共享技能；
- 1～2个特色 / 专属技能。

不要求严格固定比例。核心原则：共享技能负责构成基础能力，特色技能负责决定宠物真正的核心玩法。

# 150. 升级技能解锁节奏

## 150.1 推荐解锁节奏

第一阶段正式增加宠物通过升级自动掌握自身技能的规则（等级范围 Lv.1～Lv.50）。推荐标准技能解锁节奏：

| 等级 | 解锁内容 |
|---|---|
| Lv.1 | 主动技能① + 被动技能① |
| Lv.5 | 主动技能② |
| Lv.10 | 主动技能③ |
| Lv.15 | 被动技能② |
| Lv.20 | 主动技能④ |
| Lv.30 | 主动技能⑤ |
| Lv.35 | 被动技能③ |
| Lv.40 | 主动技能⑥ |

Lv.50 作为第一阶段成长完成节点，不强制所有宠物再获得新技能。

以上属于标准模板，不同宠物允许根据具体定位适当调整技能解锁等级，例如：Lv.25 解锁特色技能、Lv.45 解锁最终主动技能、Lv.50 解锁某个特殊被动、某只宠物拥有第7个自身主动技能。

## 150.2 节奏约束

整体必须满足：玩家在 Lv.20 左右通常已经能够形成基础完整战斗技能组合，即 Lv.20 左右通常已经拥有至少4个自身主动技能。

Lv.30～40 以后获得的新技能主要用于 Build 分化、技能替换、战术拓展，而不是单纯增加技能按钮。

## 150.3 升级后主动技能装备规则

当宠物升级获得新的自身主动技能时：

- 如果当前自身主动技能槽不足4个，可以自动装备到空位；
- 如果当前已经 4 / 4，则新技能只进入自身技能库，不得自动覆盖原有技能，界面提示「已学习新的主动技能，请前往技能页面调整战斗技能。」

被动技能升级解锁后自动生效，无需玩家进行任何额外配置。

# 151. 技能配置总量与共享控制

## 151.1 SkillDefinition 总量控制

第一阶段实际 SkillDefinition 总量继续控制在约80～100个（见第136节与第148.4节）。

需要明确：27只宠物 × 约9个自身技能 ≈ 约243次「宠物与技能的引用关系」，但不代表243个 SkillDefinition。同一个 SkillDefinition 可以被多个 PetSpecies 引用。

建议第一阶段技能结构大致控制为：

| 层级 | 数量 |
|---|---:|
| 通用 / 基础技能 | 约5～8个 |
| 九元素共享技能 | 约40～50个 |
| 定位 / 机制共享技能 | 约10～15个 |
| 宠物特色 / 专属主动和被动 | 约25～35个 |
| **最终总量** | **约80～100个** |

以上属于规划目标，不需要为了满足数字强行增加无意义技能。

## 151.2 禁止复制技能定义

禁止为了不同宠物复制相同技能配置。例如不要设计 烬牙兽_FIRE_CLAW 与 赤曜兽_FIRE_CLAW；如果二者技能效果实际上完全相同，应统一为 FIRE_CLAW，由多个宠物引用同一个 skillId。修改一次 SkillDefinition，所有引用该技能的宠物同时使用新配置。

## 151.3 规模验收

第一阶段27只宠物全部设计完成后，宠物与技能的引用关系可以达到约200次以上，但实际 SkillDefinition 仍然控制在约80～100个。

如果实际技能定义明显超过 120～130 个，需要重新检查：是否存在重复技能、是否只是名称不同、是否只是基础伤害略有不同、是否可以通过参数配置复用、是否可以使用相同 Effect 组合。

# 152. 敌方胜利互动系统

## 152.1 设计定位

本系统是**战败（§44）的负反馈增强**：玩家战败仍零惩罚（不扣金币/经验/物品/等级、无永久伤势），负反馈主要来自**获胜方带有角色特色的胜利表现**。

目标体验：

> 训练师嘴欠、Boss 会补刀、野外宠物会得意、霸主会记仇——玩家输了很气但不受资源惩罚，产生强烈再战欲望。

系统属于**表现增强功能**，不是核心战斗系统。必须数据驱动、低耦合、可逐步增强，不得显著增加战斗核心复杂度。

## 152.2 风格尺度

允许：欠揍、贱兮兮、阴阳怪气、得意、幸灾乐祸、嘴硬、精准补刀、假装安慰、假装尊重、搞笑、挑衅。

避免：现实人格攻击、严重辱骂、脏话、歧视、仇恨表达、长时间羞辱、让玩家产生被霸凌的不适感。

核心尺度：

> 让玩家觉得「这个游戏角色很欠揍」，而不是「游戏开发者在骂玩家」。

## 152.3 适用对象与表现形式

训练师 / 剧情 NPC / 劲敌 / Boss：以**台词 + 表情 + 简单动作 + 极少量宠物配合**为主。

野外宠物（普通 / 稀有 / 精英 / 霸主）不默认说人话，优先使用：

- **动作**：昂头、摇尾巴、转圈、蹦跳、打哈欠、趴下、舔爪、背过身、原地等待、甩尾、咆哮、振翅、跺脚。
- **叫声**：如「嗷呜——！」「啾！」「吼——！」。
- **系统旁白**：如「它得意地扬起了头。」「它打了个哈欠，好像刚才的战斗并没有让它认真起来。」
- 仅世界观明确允许高智慧宠物语言表达时，才可用极短文字（如「还来？」「就这？」）。

## 152.4 统一数据模型

训练师台词与野外宠物互动统一为 **VictoryInteraction**，仅表现类型不同：

```json
{
  "id": "VI_NPC_CLOSE_001",
  "winnerType": "TRAINER",
  "style": "SARCASTIC",
  "contexts": ["CLOSE_LOSS"],
  "presentationType": "DIALOGUE",
  "weight": 100,
  "text": "就差一下呢，是不是更难受了？"
}
```

```json
{
  "id": "VI_WILD_LAZY_001",
  "winnerType": "WILD_PET",
  "style": "LAZY",
  "contexts": ["CRUSHED"],
  "presentationType": "ACTION_NARRATION",
  "actionId": "YAWN",
  "weight": 100,
  "text": "它打了个哈欠，好像刚才只是在活动身体。"
}
```

## 152.5 战况标签与数据来源

首版战况标签控制约 6～10 个：

```text
NORMAL_LOSS / CLOSE_LOSS / CRUSHED / COMEBACK_LOSS
REPEATED_DEFEAT / EXCESSIVE_HEAL / EXCESSIVE_SWITCH / REPEATED_SKILL
```

（如现有系统方便，可再增加 UNDERLEVELED_CHALLENGE / OVERLEVELED_LOSS，不做硬性要求。）

数据优先原则：

> 能直接拿到的数据 > 需要简单统计的数据 > 为表现层专门新增复杂统计的数据。

BattleDefeatContext 保持轻量，只保留获胜方、回合数、可白拿的战况标签与少量行为计数；不得为嘲笑系统大规模改造战斗引擎。

## 152.6 角色风格

训练师 / NPC 使用 `victoryStyle`（每个角色一个主风格，必要时 `primaryStyle + secondaryStyle`）：

```text
ARROGANT / SMUG / SARCASTIC / PLAYFUL / CALM / HOT_BLOODED / VILLAIN / GENTLE
```

野外宠物使用 `victoryBehavior`：

```text
PROUD / PLAYFUL / FEROCIOUS / CALM / CURIOUS / TIMID / LAZY / MISCHIEVOUS
```

不建立多维人格数值、好感度或关系系统。

## 152.7 权重随机与防重复

- 候选池 → 排除最近 3～5 条 → 按 context 匹配 → 按 weight 随机。
- 无专属配置时回退公共池。
- 不设计复杂推荐算法。

## 152.8 内容规模控制

| 类别 | 首版数量 |
|---|---:|
| 公共 NPC / 训练师 | 约 100～150 条 |
| 野外宠物公共互动 | 约 60～100 条 |
| 每个重要 Boss | 15～30 条 |
| 每个野外精英 / 霸主 | 5～10 条 |
| 彩蛋 | 10～20 条 |
| 稀有宠物特色 | 1～3 条 |

普通野怪共享 `victoryBehavior` + 公共池，不为每只野怪制作海量专属台词。

## 152.9 连续挑战与复仇反馈

- 普通随机野怪：**不保存长期挑战历史**，只根据当前战斗表现触发互动。
- 固定 Boss / 精英 / 霸主：可低成本记录 `challengeCount / consecutiveDefeatCount`（复用统计键或极小表），制造野外宿敌感与重复挑战互动。
- 若需大幅修改存档系统则推迟到后续版本。
- 多次败给同一固定敌人后首次击败，可给简单特殊反馈（如 Boss「……行，这次算你赢。」、霸主沉默退开），仅对固定重要敌人实现。

## 152.10 功能边界（明确不做）

- 不新建复杂 NPC 好感度、宿敌数值、宠物记忆 AI、LLM/NLP、行为树、情绪推理、复杂历史战斗数据库。
- 不为每只普通野怪保存永久交互历史。
- 不增加数十种战况识别、复杂动画新框架、单独大型剧情系统。
- 不引入新的在线服务。
- 不改变既有战败结算（零惩罚）；只做展示与表现，不反向影响战斗数值。

## 152.11 降级策略

系统允许不同资源完整度下正常工作：

- 一级表现：专属动作 + 叫声 + 文本。
- 二级表现：已有动作 + 文本。
- 三级表现：纯文本 / 旁白。

美术资源尚未完成时，功能可先开发。

# 153. 动态难度、野外缩放、Boss 自适应与等级压制

## 153.1 全局难度

第一阶段新增全局难度：`NORMAL / ELITE / NIGHTMARE / HELL`。该设置属于单人存档，默认 `NORMAL`，可在设置页切换；影响之后创建的野外遭遇和未生成快照的 Boss。它与 Boss 原有内容难度 `NORMAL / HARD / NIGHTMARE` 独立存在，不改变原有难度解锁、掉落与幸运值规则。

## 153.2 野外有限缩放

野外以当前生效预设内等级最高的至多三只宠物均值为参考，结合地图推荐等级、地图最低/最高敌等级、全局难度偏移和刷新组波动生成。任何情况下不得突破地图范围、难度范围和游戏等级上限；玩家等级低时也不得把区域怪物压低到破坏地图节奏。野外队伍数同样受难度范围与标准上场数限制。高难可产生少量坦克/治疗/控制协同，但不得按玩家弱点构造完美克制。

## 153.3 Boss 核心与适配

Boss 核心主题、内容难度和主要技能保持固定；弱队不能让 Boss 降级。全局难度只可在配置限定范围内向上调整 Boss 等级、添加有限可选支援位、提高 AI 强度与轻量属性倍率。可选位优先满足主题队伍的角色需求，不允许重复种族或刻意针对玩家单一属性/阵容。

## 153.4 Boss 遭遇快照

玩家首次点击某个 Boss 内容难度的挑战时，必须先生成并保存遭遇快照。快照包含生成队伍、等级、属性、技能、被动、AI 强度、随机种子和当时全局难度；战败、重启、自动挑战和重复挑战均复用快照，不得通过反复进入刷出更有利的阵容。切换全局难度不修改已有快照；仅当当前难度不同于快照难度时，允许玩家确认后显式重置为当前难度，同难度不允许重掷。

## 153.5 高难有效等级

高难 Boss 战可启用玩家有效等级上限。该上限只存在于战斗临时数据中：真实等级、技能解锁、经验与存档属性点绝不回退；战斗属性依现有成长公式按 `effectiveLevel` 重算，技能仍按实际已解锁状态使用。若实际自由加点超过有效等级可获得预算，按现有六维已投入比例以最大余数法投影，且有效消耗不得超过有效预算。所有伤害、治疗、速度、护盾与状态计算都必须使用同一 BattleEngine 中的有效战斗属性。

## 153.6 明确边界

不引入世界等级、无限追踪野怪、第二套成长或战斗公式、全队强制同级、行为树、复杂职业克制网、按玩家弱点生成完美反制队、Boss 无限制属性膨胀；Boss 不因玩家弱小而降低难度。

# 游戏玩法说明（GAMEPLAY）

本文档以**玩家视角**介绍《宠物精灵》怎么玩。面向玩家，不做精确数值推导。

> 精确规则与数值以《宠物精灵游戏第一阶段需求设计文档 V1.0.md》为准；本文档若与需求文档冲突，以需求文档为准。

---

## 1. 游戏目标

收集并培养宠物，组建队伍，探索区域，挑战 Boss，完成图鉴、任务与成就，最终达成游戏完成度。

## 2. 开始游戏

- 首次进入会引导创建新游戏：设定名称、选择形象，并从三只初始宠物中选择一只。
- 新游戏会赠送少量捕捉球与恢复道具，初始宠物从 5 级开始，便于早期探索。

## 3. 宠物

- 共 **27 种**基础宠物，分属 9 种属性，稀有度从普通到传说。
- 每只宠物有六维属性、等级、资质与技能，可自由培养。

## 4. 属性

- 每只宠物有生命、力量、灵力、防御、抗性、速度等六维属性。
- 属性由种族基础、等级成长、资质修正与自由加点共同决定。

## 5. 等级

- 等级上限 **Lv.50**。
- 经验统一进入玩家的**公共经验池**，由你自主分配给宠物升级。
- 支持五种升级方式：升 1 级、升 5 级、升到指定等级、升到上限、自定义投入经验。

## 6. 资质

- 每只宠物有一组资质（0～100），影响升级时的属性成长。
- 资质越高，升级成长越好；资质在捕捉时随机生成。

## 7. 技能

- 技能分为**主动**与**被动**，来源分为宠物自身（INNATE）与技能书（BOOK）。
- 宠物自身主动技能最多装备 4 个，技能书主动技能额外携带最多 2 个（书槽）。
- 技能书主动最多学习 10 个，超限需遗忘；被动技能掌握后自动生效，无数量上限。
- 技能无 MP 消耗，以**冷却回合**限制使用。
- 宠物自身技能随等级自动解锁（约 Lv.1～40 逐步习得），无需额外消耗；每只宠物通常拥有约 5~6 个主动技能与 2~3 个被动技能，技能组合因宠物定位（输出 / 坦克 / 辅助 / 控制）而异。

## 8. 队伍

- **6 宠携带**（3 首发 + 3 候补），**3 宠上场**。
- 支持最多 **5 套队伍预设**，可自由切换。
- 队伍决定了战斗中的出战阵容。

## 9. 战斗

- 回合制：每回合每只宠物一次行动，速度决定行动顺序，每回合重算。
- 行动包括：技能、防御、换宠，野外战斗还可捕捉、逃跑。
- 手动战斗由你选择行动；自动战斗由 AI 决策。

## 10. 属性克制

- 9 种属性之间存在克制关系：克制造成更高伤害，被克制则降低。
- 使用与自身相同属性的技能会获得额外加成。
- 战斗中利用克制关系可以事半功倍。

## 11. 状态

- 战斗中会施加各类状态（增益、减益、控制、持续伤害等）。
- 部分宠物有被动技能，在特定时机自动生效。
- 技能冷却、增益 / 异常状态不跨战斗保留；HP 跨战斗保留。

## 12. 自动战斗

- 已击败过的敌人可进行自动战斗（Boss 分难度）。
- 自动战斗是真实执行，不是扫荡。

## 13. 捕捉

- 在野外遭遇野生宠物后，可压低其 HP、施加异常状态后投掷捕捉球。
- HP 越低、异常状态越多、捕捉球等级越高，捕获概率越高。
- 捕捉球分为普通 / 高级 / 特级三档。
- 捕捉成功后，可选择直接入队（队伍未满）或存入仓库。

## 14. 地图探索

- 在 2D 地图上移动（方向键 / WASD，E 键交互），探索已解锁区域。
- 区域内有野生宠物、采集点、宝箱、营地与出口。
- 营地可免费恢复全队 HP，并提供已激活营地间的免费传送。
- 探索中会触发随机事件与隐藏遭遇。

## 15. Boss

- 有 **5 个主 Boss + 3 个隐藏 / 精英 Boss**，击败后解锁更高难度（普通 / 困难 / 噩梦）。
- Boss 有控制抗性、连续控制衰减与阶段机制，击败掉落情报分档解锁。
- 挑战 Boss 可累积幸运值，用于兑换掉落；支持自动挑战。

## 16. 图鉴

- 收集与研究宠物，研究等级 Lv.0~5 逐级解锁信息。
- 研究值来自发现、捕捉、战斗、高资质、稀有技能、特殊外观等多种途径。
- Lv.5 可对野外宠物进行资质预估识别。

## 17. 任务

- 包含主线、支线与隐藏任务，通过事件推进。
- 与 NPC 对话可推进任务与剧情；新手教学会引导你上手。
- 完成支线可触发地图永久变更等效果。

## 18. 商店

- 商店出售恢复道具、材料、技能书等，随主线进度解锁商品。
- 资源不足时可通过采集、宝箱、任务与 Boss 掉落获取材料。

## 19. 技能书

- 技能书道具可让宠物学习新的主动技能，受属性 / 稀有度 / 种族限制。
- 部分技能为专属技能，不可通过学习获取。
- 技能书分为**主动技能书**与**被动技能书**两类（共 23 种：13 主动 + 10 被动）。
- **被动技能书**：学习后永久掌握对应被动，但**已学习 ≠ 当前生效**——每只宠物最多同时**启用 2 个**技能书被动（独立被动槽），其余保持「已学习未启用」，可在战斗外启用 / 停用 / 替换。
- 被动分为**固有被动**（宠物出生 / 升级自动获得，全部自动生效，不可卸下，体现宠物特色）与**技能书被动**（后天培养 / Build 调整）两大来源；同名 / 同效果被动只生效一次，取更高效果。
- 每只宠物拥有 1 个**专属核心特色被动**（如金属系「锋锐 / 破甲威慑 / 鎏金反刃」、火系「绯焰焚身」、暗系「幽蚀回噬」等），从 Lv.1 起自动生效，是定义该宠物独特玩法与元素定位的标志性机制。
- 被动技能书同样复用既有强化 / 攻击 / 回血 / 荆棘类图标，不新增美术资源。

## 20. 成就

- 完成各类目标可获得成就，解锁金币、经验、捕捉球、材料与称号等奖励。
- 部分成就为隐藏成就，达成后才会显现。

## 21. 游戏完成度

- 完成度综合主线、区域、宠物发现与捕捉、图鉴研究、Boss、支线等维度加权计算。
- 达成一定完成度可解锁相关进度反馈。

## 22. 存档与备份

- 游戏进度自动保存在本地 MySQL 中，可手动保存。
- 详情见《宠物精灵游戏第一阶段需求设计文档 V1.0.md》与后续开发规划。

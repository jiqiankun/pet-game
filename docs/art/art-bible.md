# 《宠物精灵》Art Bible（风格指南）

版本：V1.0  
状态：已确认（A0 锚点质检通过）；新增资源须遵循 [art-generation-workflow.md](art-generation-workflow.md)。

## 视觉方向

- 风格：清新幻想的 2D 游戏插画，圆润造型、轻微手绘颗粒；不写实、不暗黑、不使用像素风立绘。
- 角色：3/4 视角，面朝左前方；全身置中，四周预留 10% 以上留白；角色本身不带文字、边框或水印。
- 线条：深蓝灰色的干净中等描边，内侧细节少而明确；低分辨率缩放后仍能辨识轮廓。
- 光影：左上方暖白主光，右下方柔和冷色环境光；阴影柔和且克制。
- 色彩：柔和饱和、每个角色以 2~4 个主色为主。属性官方色为：金 `#C9B037`、木 `#66BB6A`、水 `#42A5F5`、火 `#EF5350`、土 `#8D6E63`、风 `#80CBC4`、雷 `#FFCA28`、光 `#FFF176`、暗 `#7E57C2`。
- 稀有度：普通为简洁的轮廓与局部属性光；稀有增加一个明确结构特征；珍稀增加精致材质或局部光效；传说使用克制的星辉与更丰富但不复杂的剪影，构图和体量不夸张。

## 地图与物件

- 地图：俯视正交 2D，32px tile 对齐，柔和手绘质感，光源同为左上方。
- Props：轮廓清楚、透明背景、与 tile 同尺度；不使用独立场景背景。
- 野怪：使用宠物头像的缩放派生，并用程序徽章表达行为，避免生成四类泛化野怪。

## UI 与特效

- 图标：清楚的剪影优先，粗描边，24px 仍可辨识；属性色仅作主色或角标。
- VFX：半透明、圆润粒子与明确运动方向；不包含背景、文字或 UI 框。
- UI 面板、边框、功能图标、数值反馈保留 CSS / SVG / Phaser tween，不生成位图。

## 输出约束

- 立绘、NPC、地图 Props、VFX：最终使用透明 PNG；内建生成先在纯色抠图背景上输出，再做 alpha 去背。
- Tileset：仅接收能精确切成 32px 网格、可无缝拼接的素材；未通过无缝测试不可覆盖游戏资源。
- 生命周期、命名、正式目录与验收职责统一见 [art-resource-management.md](art-resource-management.md) 和 [art-quality-standard.md](art-quality-standard.md)；本文件只维护画风与输出视觉约束。
